# /public/jumpscares/

Сюда положите картинки для джампскейров (Stage 6) — можно мемные, любые смешные/страшные.

- Форматы: `.png` или `.jpg`.
- Каждая картинка будет случайно сочетаться со звуком из `/public/jumpscares/sounds/`.
- Если папка пустая — движок Stage 6 подставит 1-2 встроенных заглушки, чтобы игра всё равно работала.
