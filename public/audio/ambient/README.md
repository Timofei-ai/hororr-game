# /public/audio/ambient/

Сюда положите фоновый эмбиент-дрон, который будет играть в цикле (`loop`).

- Ожидаемое имя файла: `ambient_ethereal.wav` (можно заменить на своё — просто обновите путь в коде, когда дойдём до Stage 3).
- Форматы: `.wav` или `.mp3`.
- Пока папка пустая — фон просто не будет играть, игра при этом не сломается.
