# /public/audio/hallucinations/

Сюда положите короткие аудио-клипы "галлюцинаций" (шёпот, шаги, голоса), которые
будут проигрываться только ОДНОМУ игроку за раз (Stage 5).

- Форматы: `.wav` или `.mp3`.
- Можно добавить сколько угодно файлов — движок будет выбирать случайный.
- Пока папка пустая — система галлюцинаций просто не будет использовать звук.
