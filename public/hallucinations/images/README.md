# /public/hallucinations/images/

Сюда кладите картинки для нового вида галлюцинации — короткая (доля секунды)
вспышка жуткого/странного изображения на весь экран, без звука джампскейра и
без тряски экрана (это Stage 5, "срывает крышу", а не Stage 6 "поймали").

- Форматы: `.png` или `.jpg`.
- Сервер сам сканирует папку — переименовывать не нужно, просто положите файл.
- Пока папка пустая, этот вид галлюцинации просто не выпадает (остальные виды
  работают как обычно).
