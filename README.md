# Horror Game (рабочее название)

Онлайн кооперативный хоррор от первого лица на Three.js + Socket.IO.
Полное ТЗ проекта — в [`PROMPT.md`](./PROMPT.md).

## Что сделано

- **Stage 1**: скелет проекта (Vite + Three.js клиент, Express + Socket.IO
  сервер), тёмная комната от первого лица с движением, фонарик на столе
  (подбирается по `E`, включается/выключается по `F`).
- **Stage 2**: ник (сохраняется между заходами), лобби в стиле Roblox — «Создать
  комнату» (получаете 6-значный код) / «Войти в комнату» (по коду друга), зал
  ожидания со списком игроков (цветная точка + ник, хост помечен), кнопка
  «Старт» только у хоста и только когда есть хотя бы 1 другой игрок (максимум
  5 человек). В игре ник висит над каждым игроком (бирка всегда развёрнута к
  камере), у каждого свой цвет. В углу экрана — список игроков (кто жив/выбыл
  — статус «выбыл» появится вместе с монстром на Stage 4).

## Как запустить

```bash
npm install
npm run dev
```

Это одновременно запустит:
- клиент на **http://localhost:5173** (открывайте эту ссылку в браузере),
- сервер на **http://localhost:3001** (в браузере открывать не нужно, это сеть).

### Проверка Stage 2 (лобби) — нужно 2 вкладки/окна браузера

1. Откройте `http://localhost:5173` в первой вкладке — введите ник, нажмите
   «Продолжить», затем «Создать комнату». Увидите 6-значный код и себя в
   списке (как хост).
2. Откройте вторую вкладку тем же адресом — введите другой ник, «Продолжить»,
   «Войти в комнату», впишите код из первой вкладки, «Войти». Обе вкладки
   должны увидеть обоих игроков в списке.
3. В первой вкладке (хост) появится и станет активной кнопка «Старт» —
   нажмите её.
4. Обе вкладки переходят в 3D-сцену — кликните по чёрному экрану в каждой,
   подвигайтесь `WASD`. В другой вкладке должен быть виден движущийся
   персонаж второго игрока с ником над головой.

Если это работает — Stage 2 пройден, дальше идёт Stage 3 (первая играбельная
локация, инвентарь и цели).

## Свои файлы (звуки/картинки для будущих стадий)

Папки уже созданы, кладите файлы прямо в них (см. README внутри каждой):
- `public/audio/ambient/` — фоновый эмбиент (`.wav`/`.mp3`).
- `public/audio/hallucinations/` — голоса/шёпот для галлюцинаций (Stage 5).
- `public/jumpscares/` — картинки для джампскейров (`.png`/`.jpg`, Stage 6).
- `public/jumpscares/sounds/` — звуки для джампскейров (`.mp3`/`.wav`, Stage 6).
