# Horror Game (рабочее название)

Онлайн кооперативный хоррор от первого лица на Three.js + Socket.IO.
Полное ТЗ проекта — в [`PROMPT.md`](./PROMPT.md).

## Stage 1 — что сделано

- Скелет проекта: клиент (Vite + Three.js) и сервер (Express + Socket.IO).
- Пустая тёмная комната от первого лица с движением (WASD + мышь, pointer lock).
- Фонарик на столе — подбирается по нажатию `E`, после чего освещает путь
  (пока без разрядки батареи — это будет добавлено на Stage 3 вместе с инвентарём).
- Клавиша `F` — включить/выключить подобранный фонарик.

## Как запустить

```bash
npm install
npm run dev
```

Это одновременно запустит:
- клиент на **http://localhost:5173** (открывайте эту ссылку в браузере),
- сервер на **http://localhost:3001** (пока используется только как заготовка под сеть, в браузер его открывать не нужно).

Что вы должны увидеть:
1. Чёрный экран с инструкцией — кликните по нему.
2. Тёмная комната. Двигайтесь `WASD`, осматривайтесь мышью.
3. Подойдите к столу у дальней стены — появится подсказка «Нажмите E, чтобы поднять фонарик».
4. Нажмите `E` — фонарик исчезнет со стола и станет освещать перед вами конус света.
5. `F` — выключить/включить фонарик.

Если всё это работает — Stage 1 пройден, можно двигаться дальше (Stage 2: лобби и сетевая синхронизация игроков).

## Свои файлы (звуки/картинки для будущих стадий)

Папки уже созданы, кладите файлы прямо в них (см. README внутри каждой):
- `public/audio/ambient/` — фоновый эмбиент (`.wav`/`.mp3`).
- `public/audio/hallucinations/` — голоса/шёпот для галлюцинаций (Stage 5).
- `public/jumpscares/` — картинки для джампскейров (`.png`/`.jpg`, Stage 6).
- `public/jumpscares/sounds/` — звуки для джампскейров (`.mp3`/`.wav`, Stage 6).
