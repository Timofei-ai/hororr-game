# Horror Game (рабочее название)

Онлайн кооперативный хоррор от первого лица на Three.js + Socket.IO.
Полное ТЗ проекта — в [`PROMPT.md`](./PROMPT.md).

## Что сделано

- **Stage 1**: скелет проекта (Vite + Three.js клиент, Express + Socket.IO
  сервер), тёмная комната от первого лица с движением, фонарик на столе
  (подбирается по `E`, включается/выключается по `F`).
- **Stage 2**: ник (сохраняется между заходами), лобби в стиле Roblox — «Создать
  комнату» (получаете 6-значный код) / «Войти в комнату» (по коду друга), зал
  ожидания со списком игроков (цветная точка + ник, хост помечен), кнопка
  «Старт» только у хоста и только когда есть хотя бы 1 другой игрок (максимум
  5 человек). В игре ник висит над каждым игроком (бирка всегда развёрнута к
  камере), у каждого свой цвет. В углу экрана — список игроков (кто жив/выбыл
  — статус «выбыл» появится вместе с монстром на Stage 4).
- **Stage 3**: инвентарь (иконки внизу экрана), 3 предмета-предохранителя,
  разбросанных по комнате (подбираются по `E`), 2 генератора (чинятся 3
  секунды по `E` — если отойти дальше пары метров, ремонт сбрасывается),
  панель целей слева вверху («Предметы: x/3», «Генераторы: y/2»), дверь
  выхода — становится зелёной и появляется уведомление, когда все цели
  выполнены. Фоновый эмбиент проигрывается через Web Audio API, если положить
  `ambient_ethereal.wav` в `public/audio/ambient/` (см. ниже).
- **Stage 4**: сущность-монстр (тёмный силуэт со светящимися красными
  глазами) — её "мозг" считает сервер, чтобы у всех была одна правда. Она
  патрулирует уровень, а заметив игрока рядом (радиус увеличивается, если у
  него включён фонарик или он двигается), гонится за ним и, поймав, ловит.
  Пойманный игрок замирает (управление блокируется) с красным экраном «ВАС
  ПОЙМАЛИ», у остальных в HUD и в 3D он отображается как выбывший. Если
  поймали всех — общее уведомление о проигрыше раунда.

## Как запустить

```bash
npm install
npm run dev
```

Это одновременно запустит:
- клиент на **http://localhost:5173** (открывайте эту ссылку в браузере),
- сервер на **http://localhost:3001** (в браузере открывать не нужно, это сеть).

### Проверка Stage 2 (лобби) — нужно 2 вкладки/окна браузера

1. Откройте `http://localhost:5173` в первой вкладке — введите ник, нажмите
   «Продолжить», затем «Создать комнату». Увидите 6-значный код и себя в
   списке (как хост).
2. Откройте вторую вкладку тем же адресом — введите другой ник, «Продолжить»,
   «Войти в комнату», впишите код из первой вкладки, «Войти». Обе вкладки
   должны увидеть обоих игроков в списке.
3. В первой вкладке (хост) появится и станет активной кнопка «Старт» —
   нажмите её.
4. Обе вкладки переходят в 3D-сцену — кликните по чёрному экрану в каждой,
   подвигайтесь `WASD`. В другой вкладке должен быть виден движущийся
   персонаж второго игрока с ником над головой.

Если это работает — Stage 2 пройден.

### Проверка Stage 3 (уровень, инвентарь, цели)

После старта матча (см. выше):

1. Дойдите до стола у дальней стены, `E` — фонарик в инвентаре внизу экрана.
2. По комнате разбросаны 3 предмета (светящиеся жёлтые кристаллы) — подойдите
   и нажмите `E` у каждого. Панель слева вверху покажет «Предметы: x/3».
3. Найдите 2 генератора (тёмные ящики с красной лампочкой) — подойдите,
   нажмите `E`, простойте 3 секунды не отходя (подсказка покажет проценты
   ремонта). Лампочка станет зелёной, счётчик «Генераторы: y/2» вырастет.
4. Когда оба счётчика дойдут до максимума — появится сообщение «Все цели
   выполнены! Дверь открыта», а панель у дальней стены станет зелёной.

Если это работает — Stage 3 пройден.

### Проверка Stage 4 (сущность-монстр)

После старта матча просто походите по уровню (особенно ближе к центру
комнаты) — рано или поздно тёмный силуэт со светящимися глазами вас заметит
и погонится. Если он вас поймает:

1. Экран окрасится в красный, появится надпись «ВАС ПОЙМАЛИ» — управление
   заблокируется.
2. У второго игрока (в другой вкладке) в списке справа сверху ваш ник
   станет зачёркнутым.
3. Если поймать всех — появится сообщение о проигрыше раунда.

Включённый фонарик и активное движение увеличивают шанс, что монстр вас
заметит издалека — стоять неподвижно в темноте безопаснее.

Если это работает — Stage 4 пройден, дальше идёт Stage 5 (система
галлюцинаций — у каждого игрока своя, персональная).

## Свои файлы (звуки/картинки для будущих стадий)

Папки уже созданы, кладите файлы прямо в них (см. README внутри каждой):
- `public/audio/ambient/` — фоновый эмбиент (`.wav`/`.mp3`).
- `public/audio/hallucinations/` — голоса/шёпот для галлюцинаций (Stage 5).
- `public/jumpscares/` — картинки для джампскейров (`.png`/`.jpg`, Stage 6).
- `public/jumpscares/sounds/` — звуки для джампскейров (`.mp3`/`.wav`, Stage 6).
